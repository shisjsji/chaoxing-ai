    凌乱的风&

    18 岁 · 信息安全技术 · 大一

    白天上课，晚上写点小工具。这个程序最初只是想把刷课的几个小时还给自己，后来慢慢变成了现在这样。

    GitHub 项目仓库 个人博客 项目官网

    这个程序做什么

    • 在桌面端跑，账号和 API Key 用 Windows 加密存在本机
    • 答题先查题库，只有平台判过满分、多人给出同一答案，或者你自己确认过的才会被复用
    • 考试在内嵌浏览器里作答，图形验证码和人脸验证由你本人完成

    用到的技术

    • Python 3.12 与 Flask，界面由 pywebview 嵌入 WebView2
    • 题库存 SQLite，指纹用题干加排序后的选项一起算
    • 答题接任意 OpenAI 兼容接口，DeepSeek 开箱能用

    遇到问题

    • 点右上角「反馈」，最近的日志会一起发过来
    • 也可以到 GitHub 开 issue
    • 设置页可以再看一遍新手教程

    考试节奏（降低被判定风险）

    低于 100% 时，考试中会按比例故意答错几题——整卷次次满分更容易被判定异常。答错会真的扣分，自己取舍；故意答错的题不会进题库。

      更新方式

      1. 下载更新包（约 190 MB）
