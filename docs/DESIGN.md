# 界面设计规范（macOS 风格）

参考 Apple Human Interface Guidelines 的 Materials / Layout / Color / Typography 四部分。
后续题库页、设置页、exe 外壳都按这套规范实现。

## 颜色

系统色板原值，浅色/深色两套。

| 用途 | 浅色 | 深色 |
|---|---|---|
| 窗口背景 | `#f2f2f7` (systemGray6) | `#1c1c1e` |
| 卡片/浮层 | `#ffffff` | `#2c2c2e` |
| 侧边栏（半透明） | `rgba(246,246,248,.72)` | `rgba(28,28,30,.72)` |
| 主文字 | `#1d1d1f` | `#f5f5f7` |
| 次要文字 | `#6e6e73` | `#98989d` |
| 分隔线 | `rgba(0,0,0,.08)` | `rgba(255,255,255,.10)` |
| 强调色 | `#007aff` systemBlue | 同 |
| 成功 | `#34c759` systemGreen | 同 |
| 警告 | `#ff9500` systemOrange | 同 |
| 危险 | `#ff3b30` systemRed | 同 |
| 中性 | `#8e8e93` systemGray | 同 |

不使用渐变、不使用高饱和自定义色，状态色只用上表四个。

## 字体

优先 SF Pro（macOS），Windows 下降级到系统栈，保证字重和字距接近。

```css
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC",
             "Microsoft YaHei", "Segoe UI", sans-serif;
```

桌面尺度（比 iOS 小一档）：

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 窗口标题 | 13 | 600 | 侧边栏顶部 |
| 页标题 | 20 | 600 | 页面大标题 |
| 分组标题 | 13 | 600 | 卡片标题 |
| 正文 | 13 | 400 | 通用 |
| 次要 | 11 | 400 | 说明、时间戳 |
| 等宽 | 11.5 | 400 | 日志 |

日志用 `ui-monospace, "SF Mono", Consolas, monospace`。

## 布局

- 8pt 网格，间距只用 4 / 8 / 12 / 16 / 20 / 24。
- 窗口级两栏：侧边栏 216px 固定 + 内容区自适应。
- 工具栏高 52px，左侧状态、右侧主操作。
- 内容区内边距 20/24，最大宽度不限（桌面应用不像网页要居中）。
- 圆角：卡片 10px，控件 6px，小标签 4px。
- 阴影：`0 1px 2px rgba(0,0,0,.04), 0 4px 12px rgba(0,0,0,.06)`，深色模式减弱为 `0 1px 2px rgba(0,0,0,.3)`。

## 材质

侧边栏和工具栏使用毛玻璃：`backdrop-filter: saturate(180%) blur(20px)`，
底色是半透明系统灰，滚动时内容从背后透出——这是 macOS 的招牌观感，也是和现在平铺白卡片最大的区别。

## 组件约定

- 开关用自绘 Toggle（44×26，圆形滑块），不用原生 checkbox。
- 单选/分段用 segmented control（灰底凹槽 + 白色滑块）。
- 主按钮用强调色实心，次要按钮用浅灰实心，危险操作只用文字色不填底。
- 列表项悬停时底色变 `rgba(0,0,0,.03)`，选中时用强调色 12% 透明度底。
- 状态用色点 + 文字，不靠整块背景色。

## 页面结构

侧边栏四项：概览、题库、设置、日志。底部固定账户信息与版本号。
工具栏：左侧当前运行状态，右侧“开始/停止”主操作。
默认停在概览页，不直接展示配置表单。
